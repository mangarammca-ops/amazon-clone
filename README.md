# Amazon Clone

Ye ek Amazon website ka clone project hai, jo online shopping website ka basic design aur functionality dikhata hai.

## Features
- Home page with product listing
- Search bar
- Shopping cart
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Repo ko download ya clone karo
2. `index.html` file ko browser mein open karo
